# 관리자 운영 기능 설정

## 배포

이번 변경에는 Realtime Database 보안 규칙이 포함되어 있습니다. 화면 코드보다 규칙을 먼저 또는 함께 배포해야 검색, 수정, 휴지통, 변경 이력, AR 운영 설정, 특별 운영일 화면, 백업·복원이 정상 작동합니다.

```bash
firebase deploy --only database
```

## 선생님별 관리자 계정

기존 대표 관리자 계정은 그대로 사용할 수 있습니다. 추가 관리자 계정은 Firebase Authentication에 만든 뒤 서버의 Admin SDK에서 다음 custom claim을 지정합니다.

```js
await getAuth().setCustomUserClaims(uid, {
  admin: true,
  adminRole: "editor"
});
```

`adminRole`은 `viewer`, `editor`, `admin` 중 하나를 사용합니다. 현재 데이터베이스 쓰기 권한의 기준은 `admin: true`이며, 세부 역할별 버튼 제한은 후속 서버 권한 정책과 함께 적용할 수 있습니다. claim을 바꾼 사용자는 로그아웃 후 다시 로그인해야 새 권한이 적용됩니다.

## 개인정보 보관기간

이 기능은 `기록·AR 관리 > 안전·설정 도구` 안에 접어 두었으며 기본값은 `자동 익명화 안 함`입니다. 관리자가 보관기간을 직접 선택해 저장한 경우에만 활성화됩니다. 이후 관리자 로그인 시 하루 한 번 보관기간이 지난 방문자와 AR 이용자 이름을 `익명`으로 바꾸고 변경 이력을 남깁니다. 이름 이외의 통계 필드는 유지됩니다. 익명화한 이름은 되돌릴 수 없으므로 활성화 전에 백업을 내려받아야 합니다.

## 특별 운영일 화면

`기록·AR 관리 > 특별 운영일 화면`에서 날짜별로 다음 기능을 설정합니다.

- AR 예약 중단 안내: 안내 제목·문구와 포스터 이미지를 등록합니다. 포스터는 기존 TV 이미지와 같은 Cloudinary 계정의 `site/special-days` 폴더에 업로드됩니다. 해당 날짜에는 공개 AR 화면이 안내 화면으로 바뀌며 일반 이용자의 Firebase AR 예약 저장도 차단됩니다.
- 방문 등록 완료 확인: 방문 등록 후 인원·등록시간·관리자 안내를 전체 화면으로 표시합니다. 완료 버튼 대기시간은 3~30초 중 선택할 수 있으며 새로고침해도 같은 브라우저 세션에서 확인 화면이 복원됩니다.

두 기능은 선택한 날짜에만 적용되고 다음 날 자동으로 해제됩니다. 특별 운영일 설정을 삭제해도 Cloudinary 원본 이미지는 자동 삭제되지 않습니다.

## 백업 복원

백업 파일은 JSON이며 현재 데이터와 병합 복원됩니다. 같은 키가 있으면 백업 값으로 갱신되므로 복원 전에 최신 백업을 한 번 더 내려받는 것을 권장합니다.
